S4-A operator kit: Figma Web (Fedora)

Spike S4 matrix v1.0.0, generated from spikes/s4-rtl/code.js. Build the frames below in a draft file in Figma Web, export them, and run node spikes/s4-rtl/s4a/classify.mjs <export.zip>.

Scope: S4-A tests Figma's text engine on text created in the editor UI. It does not test text created by the Plugin API (that is S4-B). Use the Copy buttons and don't type strings by hand: several contain invisible characters.

1. Base text-layer settings (all layers unless a row says otherwise)

Font familyper frame: Tajawal · Cairo · Noto Sans Arabic
StyleRegular
Font size28
Line height48 px (pixels, not %)
Letter spacing0
Filldefault black (#000000, 100%)
Bidi frames (asIs / rlm)text align Right, resizing Fixed width = 560 (auto height). Every row must stay on one line (height 48).
Shaping framestext align Left, resizing Auto width
FramesAuto layout vertical, gap 0, padding 0, no fill (transparent), names exactly as shown

2. Procedure (about 25–35 min)

  1. Figma Web → new draft design file. Record your browser name and version (needed for the report).
  2. First bidi frame (S4A-Tajawal-asIs): press T, click the canvas, paste row 1 (Copy → Ctrl+V), press Esc. Apply the base settings above (font Tajawal, 28/48px, Right, Fixed width 560).
  3. With the layer selected press Shift+A (auto layout). Set vertical, gap 0, padding 0, remove the frame fill, and rename the frame.
  4. Select the text layer and press Ctrl+D 9 times (10 rows). For rows 2–10: double-click the row, Ctrl+A, paste the matching string. Keep row order = table order.
  5. Duplicate the frame (Ctrl+D on the frame), rename it S4A-Tajawal-rlm, and replace all 10 texts with the RLM strings (rows look identical; the RLM is invisible).
  6. Duplicate both frames for each other font: select the frame, press Enter (selects its text layers), change the font family, rename the frame.
  7. Shaping frames: same approach with 6 rows per font, Left aligned, Auto width.
  8. Visual frames: 3 layers per font with the per-row settings (V1 fixed width 360 / V2 letter spacing 4 px / V3 Bold).
  9. Check: every bidi frame is 560 × 480, and no row wraps to two lines.
  10. Select all 12 frames → Export: PNG, 2x → Export. You get one zip with one PNG per frame, named after the frame.
  11. Copy the zip to this machine and run node spikes/s4-rtl/s4a/classify.mjs ~/Downloads/<zip> --browser "<browser + version>".
