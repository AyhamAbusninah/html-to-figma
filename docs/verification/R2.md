## 1. What the slice does

```
Chromium page ─▶ collector (extension, browser reads only) ─▶ RawPageSnapshot (internal)
              ─▶ @h2f/core (pure TS, no DOM) ─▶ CaptureDocument v1 ─▶ validate ─▶ download .json
              ─▶ plugin UI: import + validate + preview ─▶ Render
              ─▶ plugin main: buildPlan (pure) ─▶ executePlan (figma.*) ─▶ editable layers + report
```

No schema change, no backend, no new infrastructure. The file bridge is unchanged.

## 2. Supported vs. not supported (explicit)

| Area | Supported in slice 1 | Not yet: how it shows up |
|---|---|---|
| Traversal | Full DOM, open shadow roots, closed roots of custom elements, slots; skips non-rendered elements and `display:none`; **visually hidden (screen-reader-only) content skipped** | Same-origin iframe contents → placeholder + `IFRAME_NOT_CAPTURED` |
| Geometry | Document coordinates incl. scroll offset; **RTL horizontal-overflow normalization** (EXT-RTL-4); parent-relative in Figma | Rotated/scaled elements → bounding box + `TRANSFORM_UNSUPPORTED` |
| Structure | Pruning of non-painting wrappers; clipping frames for `overflow`; simplified z-order (neg z → flow → positioned → pos z); stacking contexts kept as frames | Fixed/sticky hoisting (EXT-T-9); inner-scroll expansion (EXT-C-5/6) |
| Box styles | Solid backgrounds (rgb/rgba), per-side borders (solid/dashed/dotted), per-corner radii (px/%), box-shadow (drop/inset), opacity, mix-blend-mode, `filter: blur()` | Gradients → frame named `⚠ gradient` + warning; background images → `⚠ bg-image` + warning; other filters, `clip-path`, double/groove borders (→ solid) warned; modern color syntaxes (oklch, lab…) not parsed yet |
| Text | One TEXT per DOM text node: exact characters (whitespace rules), font stack, weight, style, size, line height, letter spacing, color, alignment with `start`/`end` resolved by direction, decoration, case, line count, single vs. multi-line sizing | `text-overflow: ellipsis` → `TEXT_ELLIPSIS_NOT_APPLIED` (no "…"); `::before/::after` → `PSEUDO_ELEMENT_NOT_CAPTURED`; inline-run merging (OQ-11 B) |
| Forms | Input/textarea/select value or placeholder (placeholder color), **passwords masked at the source and again in the engine** | Native checkbox/radio/range → `NATIVE_CONTROL_APPROXIMATED` |
| Images / SVG | — | `<img>`, `<svg>`, `<canvas>`, `<video>`, `<object>`, `<embed>` → **dashed placeholder layers** named with the reason + per-node warning (R4) |
| Plugin | Frames, rectangles, editable text with fonts loaded first, nearest-weight font resolution, aliases/generics, Arabic-capable chain (PLG-F-6), per-side strokes, radii, effects, opacity, blend, clipping, placeholders, per-node failure isolation, progress, single report | Gradient/image paints (listed as "not rendered yet" in the report); provisional RLM/LRM marks (PLG-RTL-2) **unverified** |
| Safety | Page DOM untouched (verified per page); no network in plugin; node limit 10,000 | `DOM_MUTATED_DURING_CAPTURE` warning (EXT-C-3) not implemented |

## 4. Defects found by the new tests (all fixed)

| Found by | Defect | Fix |
|---|---|---|
| Figma mock | Root frame name overwritten by the capture's own name | Name set after styling |
| Figma mock | A node failing mid-configuration stayed on the page as an orphan | Nodes tracked from creation and removed on failure |
| Typings check | Blur effects lacked the now-required `blurType: 'NORMAL'` | Added |
| Typecheck | Schema literal unions were typed as `string` (TypeScript types only) | `const` type parameter. Generated schema unchanged (byte-identical, verified) |
| DOM-unchanged check (AC-EXT-8) | Closed-root API also returned **user-agent** shadow roots of built-in controls | Closed roots only for custom elements; void controls never traversed |
| Frappe slice | Screen-reader-only text (`clip: rect(0,0,0,0)`) appeared as visible text | Generic visually-hidden detection (clip rect, clip-path inset ≥ 50%, 1px clipping box) |
| Lint | Literal invisible bidi characters in sources | Replaced with `\u` escapes |

Two test-harness artifacts were identified and documented: Playwright's full-page screenshot mutates input attributes, so the DOM is compared before screenshots; and pages that animate after load are compared only once their DOM is quiet.

## 6. Recommended next increments (R2 → R3 integration, before R4)

1. Gradients (linear/radial → native gradient paints) and modern color syntax parsing: frequent on real sites, pure engine work.
2. `::before/::after` materialization (OQ-7 B): status dots, badges, separators (seen on every Frappe list).
3. `text-overflow: ellipsis` (EXT-X-8) and `DOM_MUTATED_DURING_CAPTURE` (EXT-C-3).
4. Inner scroll-area expansion (EXT-C-5/6) and fixed/sticky hoisting (EXT-T-9).
5. Then, with approval: R4 Tier-1 images (same-origin canvas) and inline SVG, which remove most placeholders.
6. As soon as any macOS/Windows access exists: one real-Figma run of the vertical slice (import `capture.json` files from `test-results/vertical-slice/`).
